## Lec. 13-2 Extended - Ses. 1 三大报表 Revisit of Financial Statements

### 13-2E-1 Balance Sheet 资产负债表

:::definition 资产负债表 Balance Sheet
在某一具体日期展示公司 assets、liabilities 和 shareholder's equity 的报表。
:::

基本恒等式：

$$
\boxed{
\text{Assets} = \text{Liabilities} + \text{Equity}
}
$$

。

Microcontroller Supplier 示例：

| Assets | Amount | Liabilities / Equity | Amount |
|---|---:|---|---:|
| Cash | 2,000 | Accounts Payable | 1,000 |
| Marketable Securities | 1,000 | Short Term Debt | 1,000 |
| Accounts Receivable | 1,000 | Current Liabilities | 2,000 |
| Inventory | 1,000 | Long-Term Debt | 1,000 |
| Other Current Assets | 1,000 | Other Long-Term Liabilities | 1,000 |
| Current Assets | 6,000 | Total Liabilities | 4,000 |
| Fixed Assets | 5,000 | Common Stock | 1,000 |
| Goodwill | 1,000 | Additional Paid In Capital | 4,000 |
| Intangibles & Other | 1,000 | Retained Earnings | 7,000 |
| Other Long-Term Assets | 3,000 | Total Equity | 12,000 |
| Total Assets | 16,000 | Total Liabilities + Equity | 16,000 |

Assets 按流动性排列：cash 最 liquid。Liabilities 按到期时间排列：due soon 到 due later。

### 13-2E-2 Income Statement 损益表

:::definition 损益表 Income Statement
展示公司在特定期间内 revenue、expenses 和 profit 的财务报告。
:::

Microcontroller Supplier 示例，期间为 Jan 1 到 Dec 31, 2025：

| Item | Amount |
|---|---:|
| Revenue | 20,000 |
| - Cost of Goods Sold | 8,000 |
| Gross Profit | 12,000 |
| - Operating Expenses | 7,000 |
| Operating Income | 5,000 |
| - Non-Operating Expenses (Income) | 1,000 |
| Pre-Tax Income | 4,000 |
| - Income Taxes | 1,000 |
| Net Income | 3,000 |
| / Shares Outstanding | 10,000 |
| Earnings Per Share | 0.30 |

几个计算：

$$
\text{Revenue} = \text{Price} \times \text{Units Sold}
$$

$$
\text{Gross Profit} = \text{Revenue} - \text{COGS}
$$

$$
\text{Operating Income}
=
\text{Gross Profit} - \text{Operating Expenses}
$$

$$
\text{Net Income}
=
\text{Pre-Tax Income} - \text{Income Taxes}
$$

$$
\text{EPS}
=
\frac{\text{Net Income}}{\text{Shares Outstanding}}
=
\frac{3000}{10000}
= 0.30
$$

。

### 13-2E-3 Cash Flow Statement 现金流量表

:::definition 现金流量表 Cash Flow Statement
展示一个期间内现金如何由 operating、investing 和 financing activities 增减。
:::

结构：

$$
\begin{aligned}
\text{Cash at end}
=&\ \text{Cash at start} \\
&+ \text{Cash from Operating Activities} \\
&+ \text{Cash from Investing Activities} \\
&+ \text{Cash from Financing Activities}
\end{aligned}
$$

。

Microcontroller Supplier 示例：

| Item | Amount |
|---|---:|
| Net Income | 3,000 |
| + Non-Cash Charges | 1,000 |
| +/- Changes in Working Capital | 1,000 |
| Cash Flow From Operating Activities | 5,000 |
| - Capital Expenditures | (2,000) |
| - Acquisitions | 0 |
| + Sale of Investments | 0 |
| Cash Flow From Investing Activities | (2,000) |
| +/- Borrow / Repay Debt | (1,000) |
| +/- Issue / Repurchase Stock | 0 |
| - Dividends | (1,000) |
| Cash Flow From Financing Activities | (2,000) |
| +/- Changes in Cash | 1,000 |
| Cash At Start Of Period | 1,000 |
| Cash at End Of Period | 2,000 |

这个报表回答的问题很直接：

$$
\text{Are you generating cash, or consuming cash?}
$$



## Lec. 13-2 Extended - Ses. 2 CapEx / OpEx 在报表中的位置

### 13-2E-4 CapEx 与 OpEx 快速定义

:::definition CapEx Capital Expenditure
公司用于购买、升级或维护长期实物资产的支出，这些资产会在多年内提供收益。
:::

例子：

- Purchasing machinery
- Building a factory
- Buying laboratory equipment

:::definition OpEx Operating Expenditure
运行组织日常业务所需的支出。
:::

例子：

- Salaries and wages
- Electricity bills
- Rent
- Maintenance

---

### 13-2E-5 行业例子 Industry Examples

| Industry | CapEx | OpEx |
|---|---|---|
| Real Estate | New roof | Window cleaning |
| Laboratory | Buy test equipment | Maintenance |
| IT | Buy servers | Cloud service |

一个常见阈值：useful life 超过 1 年，资产价值超过公司规定金额，例如 $\$2,500$，通常更可能被资本化为 CapEx。具体阈值看公司会计政策。

---

### 13-2E-6 报表影响 Statement Impact

CapEx / OpEx 在三大报表中的位置：

| Statement | CapEx | OpEx |
|---|---|---|
| Balance Sheet | 记为 asset，增加长期资产 | 通常不作为长期资产 |
| Income Statement | 通过 depreciation 分期影响 profit | 当期作为 expense 影响 profit |
| Cash Flow Statement | 通常出现在 investing activities | 通常出现在 operating activities |

例：公司买 $\$10M$ 设备，按 5 年折旧。

购买当年 cash flow：

$$
\text{Investing cash flow} = -10M
$$

每年 P&L 折旧：

$$
\text{Depreciation} = \frac{10M}{5} = 2M / \text{year}
$$

这解释了为什么公司购买昂贵设备时，不会把整个购买价一次性作为当期 operating expense。

### 13-2E-7 Extended TCO 表格

TCO 题目：

- Purchase price: $\$10M$
- M&C: $\$1M / \text{year}$
- Power: $\$0.5M$ in Year 1，之后每年涨 10%
- Resale value: $\$0M$
- Life: 5 years
- Discount rate: 10%

Actual future values：

| Year | Purchase | M&C | Power inflated 10% / yr | Total |
|---|---:|---:|---:|---:|
| Year 0 | 10.00 |  | 0.00 | 10.00 |
| Year 1 |  | 1.00 | 0.50 | 1.50 |
| Year 2 |  | 1.00 | 0.55 | 1.55 |
| Year 3 |  | 1.00 | 0.61 | 1.61 |
| Year 4 |  | 1.00 | 0.67 | 1.67 |
| Year 5 |  | 1.00 | 0.73 | 1.73 |
| Total | 10.00 | 5.00 | 3.06 | 18.06 |

Present value formula：

$$
PV_i = \frac{FV_i}{(1+r)^i}
$$

M&C present values：

| Year | Future M&C | PV at 10% |
|---:|---:|---:|
| 1 | 1.00 | 0.91 |
| 2 | 1.00 | 0.83 |
| 3 | 1.00 | 0.75 |
| 4 | 1.00 | 0.68 |
| 5 | 1.00 | 0.62 |
| Total | 5.00 | 3.79 |

源表口径的 PV TCO：

| TCO Analysis | Totals | Year 0 | Year 1 | Year 2 | Year 3 | Year 4 | Year 5 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Purchase Price | 10.0 | 10.0 |  |  |  |  |  |
| M&C (PV) | 3.8 |  | 0.91 | 0.84 | 0.75 | 0.68 | 0.62 |
| Resale (PV) | 0.0 |  |  |  |  |  | 0.0 |
| Power | 2.5 | 0.0 | 0.5 | 0.5 | 0.5 | 0.5 | 0.5 |
| Present Value Total | 16.3 |  |  |  |  |  |  |

按这个表：

$$
TCO_{actual} = 18.06M
$$

$$
TCO_{PV} = 16.30M
$$

。

现值口径更适合长期设备比较，因为它把未来费用换到了同一时间基准。
