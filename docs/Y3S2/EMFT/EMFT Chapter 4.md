::: example 例题2：高斯定理应用
::: stem
一个半径为 $R$ 的均匀带电球体，总电荷量为 $Q$。
求球内外的电场分布 $\vec{E}(r)$。
:::
::: solution
取半径为 $r$ 的同心球面为高斯面：

**球外**（$r > R$）：

$$\oint \vec{E} \cdot d\vec{S} = \frac{Q}{\varepsilon_0} \implies E = \frac{Q}{4\pi\varepsilon_0 r^2}$$

**球内**（$r < R$）：

$$E = \frac{Qr}{4\pi\varepsilon_0 R^3}$$
:::
:::
