# MindMap

这里记录 `mindmap` 代码块的展示效果。它适合放在章节开头、课程总览或复习提纲中，把 Markdown 层级直接变成可拖拽、可缩放、可折叠的思维导图。思维导图默认全部展开，工具条支持保存 SVG、保存 PNG 和保存 PDF，PDF 会打开专门的浏览器打印页面。

## 样例

```mindmap CPS 复习总览
# CPS 复习总览

## 幅度调制
- DSB-SC
  - 同步解调
  - 复指数解调
- DSB-WC
  - 包络检波
  - 整流检波
- SSB
  - 希尔伯特变换
  - 相移法
  - 选择滤波法
- VSB
  - 渐变截止滤波器
  - 正交形式

## 角度调制
- FM 带宽
  - NBFM
  - WBFM
- FM 解调
  - 微分器与包络检测
  - PLL
  - 斜率检测
- FM 生成
  - 直接法
  - 阿姆斯特朗间接法

## 数字调制
- PCM
- ASK
- PSK
- FSK
- QAM
- OFDM

## 公式节点
- 质量损失
  - $L(y)=k(y-m)^2$
```

## 无标题样例

```mindmap
# 无标题思维导图

## 控制区
- 标题留空时
- 胶囊按钮仍在最右侧
```

## 使用方法

在 Markdown 里写 `mindmap` 代码块即可。代码块语言名后面的文字会作为思维导图标题显示。

````md
```mindmap 可选标题
# 根节点

## 一级分支
- 二级节点
- 二级节点
  - 三级节点

## 另一个分支
- 适合章节总结
- 适合复习路线
```
````

如果不想显示标题，可以只写：

````md
```mindmap
# 根节点
## 分支
- 节点
```
````
