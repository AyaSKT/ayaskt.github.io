## Variant: Liquid Dock Tabs

### Design stance
把导航右侧做成更像 iOS dock 的玻璃 tab bar，强调按钮的触感和选中项上浮。

### Key choices
- Layout: 每个 tab 是独立小块，文字更短，整体更像工具栏。
- Typography: 更小字号和短标签，减少横向压力。
- Color: 同样沿用站点渐变，但用较强的玻璃浮层。
- Interaction: hover 会轻微上浮，点击可打开下拉菜单。

### Trade-offs
- Strong at: 个性更强，移动端横向滑动时也比较好看。
- Weak at: 需要把“第一学年/第二学年/第三学年”缩短为“大一/大二/大三”才自然。

### Best for
- 想让导航更像 App 控件，而不是传统文档站导航。
